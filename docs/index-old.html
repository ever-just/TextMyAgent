Setup Instructions 
Set up TEXTMYAGENT - an AI assistant that works via iMessage.

## What to do:
1. Clone the repo: git clone https://github.com/ever-just/bluebubbles-ai-agent.git
2. Navigate to: cd bluebubbles-ai-agent/agent-service
3. Install dependencies: npm install
4. Copy .env.example to .env
5. Start Docker services: docker-compose up -d (for PostgreSQL and Redis)
6. Configure .env with these required values:
   - ANTHROPIC_API_KEY: Get from https://console.anthropic.com
   - BLUEBUBBLES_URL: Usually http://localhost:1234
   - BLUEBUBBLES_PASSWORD: Your BlueBubbles server password
   - DATABASE_URL: postgres://postgres:password@localhost:5432/agent_db
   - REDIS_URL: redis://localhost:6379
   - ENCRYPTION_KEY: Generate with `openssl rand -hex 16`
   - SESSION_SECRET: Generate with `openssl rand -base64 32`
7. Build and start: npm run build && npm start
8. Verify health: curl http://localhost:3000/health

## Prerequisites the user needs:
- macOS with iMessage signed in
- BlueBubbles Server installed and running (https://bluebubbles.app)
- Node.js 18+ and Docker Desktop installed
- Anthropic API key

## After setup:
- Configure BlueBubbles webhook to http://localhost:3000/webhook/messages
- Test by sending a message to the Mac's phone number

Honest Comparisons

There are other AI assistants out there. Here's how we stack up — the good and the bad.

vs. OpenClaw

OpenClaw wins: Multi-platform (WhatsApp, Telegram, Discord, Slack), browser control, full system access, plugin ecosystem. More powerful for power users.

TEXTMYAGENT wins: iMessage-native (no extra apps), simpler setup, focused feature set. OpenClaw requires more technical setup and runs $24-29/mo for cloud. We're free and open source.

vs. Poke.ai

Poke wins: Proactive — it reads your email/calendar and reaches out before you ask. Polished UX with one-tap actions. VC-backed with dedicated team.

TEXTMYAGENT wins: Self-hosted (your data stays yours), no subscription, fully customizable. Poke is a black box; we're open source. You own the relationship with your AI.

vs. Tomo.ai

Tomo wins: Broader scope — hotel bookings, dinner reservations, deep calendar integration. More "concierge" than "assistant."

TEXTMYAGENT wins: macOS-only means tighter iMessage integration. No monthly fee. You can extend it yourself. Tomo is iOS/Android; we're for Mac users who want control.

vs. Martin (trymartin.com)

Martin wins: Multi-channel (SMS, WhatsApp, Slack, email, phone calls). Slick mobile app. YC-backed, actively developed.

TEXTMYAGENT wins: No subscription ($20+/mo for Martin). Self-hosted = privacy. Martin's a service; we're infrastructure you own. Your AI, your rules, your data.

vs. Text.ai / TextMei

They win: Works on any phone (even feature phones via SMS). No smartphone required. Carrier-level integration.

TEXTMYAGENT wins: Richer capabilities (email, triggers, memory). iMessage means better UX on Apple devices. Self-hosted means no per-message costs or rate limits.

vs. n8n AI Agents

n8n wins: 600+ integrations, visual workflow builder, enterprise-ready. More flexible for complex automation.

TEXTMYAGENT wins: Purpose-built for conversational AI via text. n8n requires building workflows; we're ready to chat out of the box. Different tools for different jobs.

The Bottom Line

Choose TEXTMYAGENT if: You want a self-hosted, privacy-first AI assistant that lives in iMessage, you're comfortable with basic terminal commands, and you value owning your data and your AI relationship.

Choose something else if: You need multi-platform support (Android, WhatsApp), want a fully managed service with zero setup, or need enterprise features like team collaboration.

OS requirement: macOS only. This isn't a limitation we chose — it's because iMessage only runs on Apple hardware. BlueBubbles bridges iMessage to our agent, and that requires a Mac.
