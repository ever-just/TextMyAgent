What is TEXTMYAGENT?

TEXTMYAGENT turns your iMessage into an interface for a Claude-powered AI assistant named Grace. Send a text, get intelligent responses. Set reminders, send emails, search the web — all through the Messages app you already use.

🧠

Claude AI Powered

Anthropic's Claude provides intelligent, context-aware conversations with memory.

Native iMessage

Self-Hosted

Extensible Tools

Reminders, email, triggers, web search — and easy to add your own.

Set up TEXTMYAGENT - an AI assistant that works via iMessage.

## What to do:
1. Clone the repo: git clone https://github.com/ever-just/bluebubbles-ai-agent.git
2. Navigate to: cd bluebubbles-ai-agent/agent-service
3. Install dependencies: npm install
4. Copy .env.example to .env
5. Start Docker services: docker-compose up -d (for PostgreSQL and Redis)
6. Configure .env with these required values:
   - ANTHROPIC_API_KEY: Get from https://console.anthropic.com
   - BLUEBUBBLES_URL: Usually http://localhost:1234
   - BLUEBUBBLES_PASSWORD: Your BlueBubbles server password
   - DATABASE_URL: postgres://postgres:password@localhost:5432/agent_db
   - REDIS_URL: redis://localhost:6379
   - ENCRYPTION_KEY: Generate with `openssl rand -hex 16`
   - SESSION_SECRET: Generate with `openssl rand -base64 32`
7. Build and start: npm run build && npm start
8. Verify health: curl http://localhost:3000/health

## Prerequisites the user needs:
- macOS with iMessage signed in
- BlueBubbles Server installed and running (https://bluebubbles.app)
- Node.js 18+ and Docker Desktop installed
- Anthropic API key

## After setup:
- Configure BlueBubbles webhook to http://localhost:3000/webhook/messages
- Test by sending a message to the Mac's phone number

Architecture

TEXTMYAGENT is built with a modular, service-oriented architecture:

┌─────────────────────────────────────────────────────────────────┐ │ Your iPhone │ │ (sends iMessage) │ └─────────────────────────────────────────────────────────────────┘ │ ▼ ┌─────────────────────────────────────────────────────────────────┐ │ BlueBubbles Server │ │ (macOS ↔ iMessage bridge) │ └─────────────────────────────────────────────────────────────────┘ │ webhook ▼ ┌─────────────────────────────────────────────────────────────────┐ │ TEXTMYAGENT │ │ ┌─────────────┐ ┌──────────────┐ ┌─────────────────────────┐ │ │ │ Message │→ │ Claude │→ │ Tool Registry │ │ │ │ Router │ │ Service │ │ (reminders, email...) │ │ │ └─────────────┘ └──────────────┘ └─────────────────────────┘ │ │ │ │ │ │ ▼ ▼ │ │ ┌─────────────┐ ┌─────────────────────────┐ │ │ │ Context │ │ Reminder/Trigger │ │ │ │ Service │ │ Services │ │ │ └─────────────┘ └─────────────────────────┘ │ └─────────────────────────────────────────────────────────────────┘ │ │ ▼ ▼ ┌─────────────────┐ ┌─────────────────────────┐ │ PostgreSQL │ │ Redis │ │ (messages, │ │ (job queues) │ │ users) │ │ │ └─────────────────┘ └─────────────────────────┘

Configuration

Key environment variables in .env:

.env 
# Required
ANTHROPIC_API_KEY=sk-ant-...
BLUEBUBBLES_URL=http://localhost:1234
BLUEBUBBLES_PASSWORD=your-password
DATABASE_URL=postgres://postgres:password@localhost:5432/agent_db
REDIS_URL=redis://localhost:6379
ENCRYPTION_KEY=your-32-char-key
SESSION_SECRET=your-session-secret

# Optional - Model
ANTHROPIC_MODEL=claude-sonnet-4-5-20250929
ANTHROPIC_RESPONSE_MAX_TOKENS=600

# Optional - Email
AGENTMAIL_API_KEY=am_...
AGENTMAIL_ENABLED=true

# Optional - Features
ANTHROPIC_ENABLE_WEB_SEARCH=true
ENABLE_DUAL_AGENT=true

Customization

The AI personality is defined in agent-service/src/agents/prompts/grace_system_prompt.md. You can customize:

  • Name — Change "Grace" to any name
  • Personality — Casual, professional, or custom
  • Response length — Short texts or detailed responses
  • Tool usage — Enable/disable specific tools
  • Custom instructions — Add your own rules

See the Prompt Customization Guide for details.
