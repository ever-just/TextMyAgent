Setup Instructions 
Set up TEXTMYAGENT - an AI assistant that works via iMessage.

## What to do:
1. Clone the repo: git clone https://github.com/ever-just/bluebubbles-ai-agent.git
2. Navigate to: cd bluebubbles-ai-agent/agent-service
3. Install dependencies: npm install
4. Copy .env.example to .env
5. Start Docker services: docker-compose up -d (for PostgreSQL and Redis)
6. Configure .env with these required values:
   - ANTHROPIC_API_KEY: Get from https://console.anthropic.com
   - BLUEBUBBLES_URL: Usually http://localhost:1234
   - BLUEBUBBLES_PASSWORD: Your BlueBubbles server password
   - DATABASE_URL: postgres://postgres:password@localhost:5432/agent_db
   - REDIS_URL: redis://localhost:6379
   - ENCRYPTION_KEY: Generate with `openssl rand -hex 16`
   - SESSION_SECRET: Generate with `openssl rand -base64 32`
7. Build and start: npm run build && npm start
8. Verify health: curl http://localhost:3000/health

## Prerequisites the user needs:
- macOS with iMessage signed in
- BlueBubbles Server installed and running (https://bluebubbles.app)
- Node.js 18+ and Docker Desktop installed
- Anthropic API key

## After setup:
- Configure BlueBubbles webhook to http://localhost:3000/webhook/messages
- Test by sending a message to the Mac's phone number

How is this different?

You've seen AI assistants. Here's why this one matters.

vs. ChatGPT / Claude Apps

Those require opening an app, logging in, and breaking your flow. TEXTMYAGENT lives in Messages — the app you're already in 50 times a day. Zero friction.

vs. Siri

Siri is great for quick commands but can't hold a conversation, remember context, or do complex tasks. TEXTMYAGENT remembers everything and can chain actions together.

vs. Cloud AI Services

Most AI assistants run on someone else's servers. Your conversations, your data — all stored elsewhere. TEXTMYAGENT runs on your Mac. Your data never leaves your hardware.

vs. Zapier / Make

Automation tools are powerful but require setup for each workflow. TEXTMYAGENT understands natural language — just tell it what you want and it figures out how.

vs. Email Assistants

Email-based AI is slow and formal. Text is instant and casual. Ask a question, get an answer in seconds. No subject lines, no signatures.

vs. Building Your Own

You could wire up Claude + webhooks + a database yourself. Or you could clone this repo and have it running in 10 minutes. We did the hard part.
